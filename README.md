# FEZTIVAL-Store
`FeZTivAL Store` adalah aplikasi toko game CLI berbasis Java yang memakai array untuk menyimpan 20 game, sistem daftar/login (maksimal 3x percobaan), pembelian dengan cek saldo &amp; kembalian, anti beli ganda, library game, serta riwayat transaksi. Seluruh logika masih terpusat di fungsi `main` dengan penyimpanan sementara di memori.
